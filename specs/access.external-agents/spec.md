# Зовнішні агенти: агент тестів забирає screen object

> Частина [основної специфікації](../SPEC.md), розділ [11. Доступ: CLI, MCP, API](../SPEC.md#access); стосується також: [15. Агент станції](../SPEC.md#agent) ([agent.station-mcp](../agent.station-mcp/spec.md)), [6. Інспектор і автоматизація](../SPEC.md#inspector). Принципи продукту — у [розділі 13](../SPEC.md#rules), правила роботи з кодом — в [AGENTS.md](../../AGENTS.md); тут вони не повторюються.

- **ID:** `access.external-agents`
- **Статус:** draft
- **Етап за документом:** v1 (зовнішні агенти)
- **Як зроблено:** [design.md](design.md) (буде після погодження)

## Проблема й користувач

Тести пише окремий агент — агент тестів у Kiro crew. Він працює в репозиторії автотестів, сам вирішує, коли йому потрібні екрани, і кладе код у репозиторій. Станція не має пхати йому файли: агент сам звертається до неї й забирає збережені пакети screen object ([autotests.screen-objects](../autotests.screen-objects/spec.md)).

Зараз MCP станції обслуговує лише вбудованого агента ([agent.station-mcp](../agent.station-mcp/spec.md), критерій 2), а токен створюється на кожен запуск і віддається лише йому. Цей крок відкриває станцію зовнішнім агентам на цьому Mac, лише на читання й лише для автотестів. Решта інструментів для зовнішніх агентів — пізніше.

## Критерії приймання

Підключення

1. **Дано** налаштування станції, **тоді** доступ зовнішніх агентів за замовчуванням вимкнено; користувач вмикає його перемикачем і бачить готовий фрагмент `mcp.json` для свого агента.
   Тест: немає
2. **Дано** увімкнений доступ, **тоді** зовнішній агент підключається командою `vision-inspector mcp --station` (міст stdio → MCP живої станції). Міст сам знаходить запущену станцію й отримує тимчасовий токен; сервер, як і раніше, слухає лише `127.0.0.1`, а без токена відповідає 401.
   Тест: немає
3. **Дано** станцію, яку не запущено чи в якій доступ вимкнено, **тоді** інструменти мосту не падають, а відповідають простими словами, що зробити («Запустіть станцію», «Увімкніть доступ зовнішніх агентів у налаштуваннях»).
   Тест: немає
4. **Дано** зовнішнього агента, **тоді** йому доступні лише інструменти цієї фічі; інструментів змін, керування пристроєм і даних сесії (трафік, логи) він не бачить.
   Тест: немає

Інструменти (лише читання)

5. **Дано** `autotests_packages`, **тоді** агент отримує список пакетів screen object проєкту (за замовчуванням активного, або за назвою проєкту): назва, дата, платформа, версія застосунку, кількість screen object, чи позначено «Готово для автотестів». Без деталей.
   Тест: немає
6. **Дано** `autotests_package_get`, **тоді** агент отримує screen object пакета: назву, стани, відібрані елементи з локаторами й згенерований код на Kotlin. Стиснуте дерево — лише на явне прохання, скриншот — лише на явне прохання й зменшений.
   Тест: немає
7. **Дано** будь-яку відповідь, **тоді** діють ліміти розміру й приховування даних, як для вбудованого агента ([agent.station-mcp](../agent.station-mcp/spec.md), критерії 10 і 15).
   Тест: немає

Видимість

8. **Дано** звернення зовнішнього агента, **тоді** воно записується в журнал станції ([station.debug-log](../station.debug-log/spec.md)): коли, який інструмент, який пакет. У налаштуваннях видно, коли агент звертався востаннє.
   Тест: немає

## Поведінка й інтерфейс

- Налаштування → «Оператор» (чи окремий розділ «Доступ») → «Зовнішні агенти»: перемикач, фрагмент `mcp.json` з кнопкою «Копіювати», останнє звернення.
- Пакет, який забрав агент тестів, позначено в списку пакетів проєкту.

## Безпека й приватність

- Доступ лише з цього Mac і лише після явного ввімкнення.
- Токен тимчасовий, живе до перезапуску станції; постійних ключів у мосту й у налаштуваннях агента немає.

## Метрика корисності

Кількість пакетів, які забрав агент тестів.

## Відкриті питання

- Як міст отримує тимчасовий токен, не порушивши правило про секрети: файл у теці даних, доступний лише користувачу, чи Keychain (він прив'язаний до назви застосунку, тож dev і встановлена збірка різні).
- CLI-варіант (`vision-inspector autotests list | get`) для агента, якому зручніше викликати команду, — тим самим мостом; агент тестів уміє обидва, тож поки лише MCP.
- Чи може агент тестів попросити станцію згенерувати чи перегенерувати код (а не лише забрати готовий).
