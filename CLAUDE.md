## Лише для Claude Code

- **Нова фіча чи зміна поведінки** — skill `spec-feature` (`.claude/skills/spec-feature/SKILL.md`): спека → дизайн і план → код → перевірка → коміт.
- **Правила для окремих файлів** у `.claude/rules/` вантажаться самі, коли працюєш із ними: спеки (`specs/**`), тексти інтерфейсу (`locales/**`, `*.jsx`).
- **Подивитися інтерфейс наживо:** `npx electron-vite dev -w --remoteDebuggingPort 9333` і керування через CDP на `http://127.0.0.1:9333/json`. Вікно може бути сховане: тоді анімації стоять, і для знімка елементи з `opacity: 0` треба показати стилем. Щоб не чіпати даних користувача (налаштування, задачі, розмови агента), запускати копію з власною текою: `STATION_DATA_DIR=<тека в scratchpad> npx electron-vite dev …`. Після перевірки зупинити свою копію (не чіпати копії користувача) й вимкнути симулятор, якщо вмикав його сам.
- **Залишені сесії Appium** на пристрої заважають новим: завершуй сесії, які створив сам.
