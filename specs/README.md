# Специфікації Station#1

Почни з **[SPEC.md](SPEC.md)** — основної специфікації продукту. Вона поділена на розділи; кожен розділ описує частину продукту й посилається на специфікації її фіч у `specs/<id>/spec.md`, а ті посилаються назад на свій розділ.

- Фіча — тека `specs/<id>/`: `spec.md` (що й навіщо), `design.md` (як зроблено), `tasks.md` (план, поки в роботі). Шаблони — у [_templates](_templates/).
- Процес: [SPEC.md → Процес](SPEC.md#process). Принципи продукту: [SPEC.md → розділ 13](SPEC.md#rules). Правила роботи з кодом: [AGENTS.md](../AGENTS.md).
